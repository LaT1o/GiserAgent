# 项目状态报告

按以下步骤为用户的项目生成一份结构化报告：

1. 用 `ls` / `find` 工具浏览项目根目录，识别项目类型（语言、框架、入口文件）。
2. 查看关键文件（README、配置文件、入口）理解项目用途。
3. 如项目使用 git，用 `git status` / `git log --oneline -10` 了解近期改动（只读命令）。
4. 如存在 todo 相关记录，汇总当前任务状态。

输出格式：

```markdown
# 项目报告：<项目名>

## 基本信息
- 类型 / 技术栈：
- 工作目录：

## 目录结构概览
（一级目录及用途，不超过 10 行）

## 近期改动
（如可获取，最近 5-10 条；否则说明"无 git 历史可查"）

## 待办 / 进行中
（从 todo 或代码中的 TODO 注释提取，无则写"暂无"）
```

注意：只读调研，不修改任何文件。
